# Security Policy

ReelWeave runs **entirely locally** — no servers, no API keys, no telemetry, no network calls
beyond downloading open models from Hugging Face / Ollama. Your footage never leaves your machine.

If you discover a security issue (e.g. a command-injection path in the ffmpeg invocation), please
report it privately via **GitHub Security Advisories** ("Report a vulnerability") rather than a
public issue. We'll respond as soon as we can.
